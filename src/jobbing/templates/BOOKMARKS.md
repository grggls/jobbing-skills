# Job Board Bookmarks

The `scan` skill fetches every link in this file and looks for jobs that fit
CONTEXT.md. This file stays on your computer (git ignores it).

Rules:

- Use one `## Category` heading per group.
- Use one markdown link per line: `- [Label](https://...)`.
- Prefer search URLs that already filter for your role, location, or remote.
- Company career pages work well too.

Replace the examples below with boards for your own field.
